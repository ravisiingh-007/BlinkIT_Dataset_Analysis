# Blinkit Grocery Data Analysis & Power BI Dashboard

## 📊 Project Overview

This project analyzes Blinkit grocery sales data using **Microsoft Power BI** to understand sales performance, product characteristics, outlet performance, and customer-facing business metrics.

The dashboard provides an interactive view of key KPIs and allows users to explore sales performance across different product and outlet dimensions.

---

## 🎯 Business Objectives

- Analyze overall sales performance.
- Understand sales distribution by product category.
- Compare sales across different outlet types and sizes.
- Analyze sales by outlet location.
- Understand the impact of item fat content on sales.
- Track sales trends based on outlet establishment year.
- Provide interactive filtering for business users.

## 📈 Dashboard Analysis

The dashboard contains multiple visualizations, including:

### Product Analysis
- Sales by Item Type
- Sales by Item Fat Content
- Product-level decomposition analysis

### Outlet Analysis
- Sales by Outlet Type
- Sales by Outlet Size
- Sales by Outlet Location Type
- Sales trend by Outlet Establishment Year

### Detailed Analysis
A pivot-style table provides:

- Outlet Type
- Total Sales
- Average Sales
- Number of Items
- Average Ratings
- Average Item Visibility

---

## 🎛️ Interactive Filters

Users can dynamically filter the dashboard using:

- Item Type
- Outlet Size
- Outlet Location Type
- Metrics

These filters allow users to perform focused analysis and compare different business segments.

## 📊 Key Business Questions

This dashboard helps answer questions such as:

1. What is the overall sales performance?
2. Which item categories contribute most to sales?
3. How does sales performance vary by outlet type?
4. Which outlet locations generate higher sales?
5. How does outlet size relate to sales?
6. How do sales vary based on item fat content?
7. How has sales performance changed by outlet establishment year?
8. How do ratings and item visibility vary across outlet types?
